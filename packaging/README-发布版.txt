拾光图库 v 1.0.7 · Windows 10/11 64 位

安装与使用
1. 运行安装程序，可选择软件安装位置。
2. 首次安装时选择照片文件夹。以后在软件内点击“照片来源”更换文件夹，或开启全盘模式选择磁盘，不复制导入照片。
3. 完成后通过桌面或开始菜单的“拾光图库”启动。无需另装 Python、无需账号，浏览和处理均在本机完成。
4. 软件以独立 Windows 窗口运行，不会再打开 Edge 或 Chrome。安装程序会检查 Microsoft Edge WebView2 Runtime，缺失时自动安装。

已有功能
真实照片缩略图带、悬停单张缩略图时在其上方显示放大预览卡片、附近缩略图预加载、全图库定位、全部照片、日期吸顶/折叠、文件夹、虚拟相册、收藏、长按拖选、双击空白取消选择、Ctrl+Z 撤销选择、悬浮操作栏、复制图片、复制原文件、ZIP 分享包、回收站删除、EXIF/色深、颜色直方图、滚轮缩放、RAW 全尺寸 16 bit 解码。
RAW 使用 LibRaw，不包含 Lightroom 调整；相机型号/文件损坏等因素可能影响某些 RAW 的支持。16 bit 输出与原 RAW 位深、显示器位深是不同概念。

数据位置
相册、照片索引和缓存：%LOCALAPPDATA%\ShiguangGallery\catalogs\对应目录编号
照片来源设置：%LOCALAPPDATA%\ShiguangGallery\source-settings.json。首次启动从安装向导保存的 PhotoRoot 初始化。旧便携版更新后会继续使用原 data 目录及其中的来源设置。
应用内更新开始安装前，会在 %LOCALAPPDATA%\ShiguangGallery\update-backups 保存照片来源设置和图库数据库的本机快照；不会上传这些文件。
默认分享导出：当前用户“文档”中的“拾光图库分享”，可在操作时另选位置。
更换浏览范围：点击“照片来源”。关闭“浏览本机所有照片”时选择一个文件夹，开启时勾选要扫描的本机磁盘、SD 卡或外接存储；每次切换模式需要重新选择，应用后开始扫描。文件夹与各磁盘组合独立保存相册和收藏，切回原来源可继续使用原相册。仅切换开关或取消对话框不会启动扫描。
卸载只移除程序及快捷方式，保留照片和用户数据。若要迁移相册，请同时备份用户数据；仅复制照片到另一台电脑不会自动迁移分组。

缩略图带保持固定排列：悬停小照片时，在鼠标附近、缩略图带上方显示单张放大预览卡片，不再使用中心放大、两侧渐小的扇形效果，也不会遮住悬停的小照片。点击或拖动后松开切换照片。滚轮或两侧箭头浏览附近缩略图，下方“全图库定位”可跳到任意位置。已预加载的缩略图直接显示，首次未缓存的图片（尤其 RAW）仍需要读取时间。

粗选定位：点击或拖动“全图库定位”时，选中的照片固定显示在缩略图带正中央，并标记“定位”。首尾不足的缩略图位置留白。普通鼠标悬停不改变缩略图带的定位。

全盘浏览只读取勾选的本机磁盘、SD 卡或外接存储，并跳过系统、常见程序目录、缓存、回收站、隐藏目录和 Lightroom 预览目录；无法访问或离线的目录不会删除已有相册记录。原照片不会移动。可边扫描边浏览，也可再次更换来源；复制、分享或删除进行中需等操作完成。

更新说明：新版本首次打开会显示本次新增功能与问题修复，关闭后不再重复提示。可点击侧栏“更新说明”查看，并用旁边的箭头收起或展开历史记录。

联网更新：应用启动时会在后台检查更新；发现可下载的新版本时，窗口顶部显示金色更新按钮。已是最新版本时不显示“检查更新”文字，仍可点击顶部更新图标手动检查。更新安装前会校验 SHA-256，并为本机照片来源和图库数据库创建快照。默认从拾光图库 GitHub 更新通道读取版本；也可在 %LOCALAPPDATA%\ShiguangGallery\update-channel.json 配置自定义 JSON 地址。

1.0.0beta3 浏览与选片
关闭大图或按 Esc 后，主界面定位并高亮最后浏览的照片。“回到当前照片”将缩略图带重置到当前大图。
底部坐标按照片顺序分布，可点击跳转；全部照片或大于 31 天的范围显示年月日，其余显示月日和时分。跨年短范围保留年份，避免歧义。
点击“选择当前照片”逐张挑选，或开启“多选缩略图”点击勾选；左右箭头和时间轴仍可切换大图。点击“加入相册”，再选“新建相册并加入”即可批量整理。多选状态和主界面同步。

1.0.0beta4 品牌图标
使用深翡翠绿、暖白叠片与柔金色光点的新图标，统一桌面、程序、窗口及界面标识，提供 16–256 像素 Windows 图标。

1.0.0beta5 多国语言
点击侧栏或大图界面的地球图标，选择九种界面语言，立即生效并保存在本机 ui-preferences.json。切换不会重载页面；原照片、相册名称与选择状态保持。界面名称按语言本地化：Lightkeeper、ひかり帖、빛담、Éclats、Lichtmomente、Instantes、Lume、Светопись。


1.0.0beta6 文件夹与全屏浏览
右击文件夹卡片选择重命名，或进入文件夹后点击标题名称。名称会同步修改磁盘上的真实目录，照片编号、相册及收藏保留；其他软件引用的旧路径可能需要重新指定。来源根目录、磁盘、程序及数据目录不能在图库中重命名。
大图右侧箭头可收起或展开照片信息，默认显示。右上角全屏按钮进入真正的屏幕全屏，保留底部缩略图和时间坐标；鼠标移到底边展开，离开后收起，拖动时不收起。Esc 先退出全屏，信息栏恢复先前状态；再次 Esc 返回主界面并定位当前照片。


1.0.0beta6.1 全屏缩略图修复
修复放大缩略图被底部容器裁切。全屏的缩略图与放大预览区域背景透明，仅最下方时间进度条保留底色。小缩略图紧贴拼接，悬停放大时保留照片原始比例，中心最大、两侧逐渐缩小。自动收起时同步隐藏放大预览，避免残留。
全屏时，日期、缩略图名称和浏览提示显示在顶部菜单，避免文字与照片颜色冲突。主界面左下方可滚动查看 beta1 至 beta6.1 的更新内容；首次打开修订版仍会展示最新说明。

1.0.0beta7 深色界面
图库总览采用深色背景、暖金色操作按钮与紧凑照片网格，右侧显示当前照片的基础信息和颜色直方图。原有搜索、格式筛选、照片来源、文件夹、收藏、相册、多选、全屏与时间轴操作继续可用。
设计稿中的 AI 搜索、评级、云同步、照片调色与 SD 卡导入等尚未实现的功能未加入本软件。

1.0.0beta8 选片与筛选
多选时操作栏随页面滚动保持可见。照片单击更新右侧信息，双击进入大图；右击可加入相册、收藏、复制、分享、在资源管理器中显示，以及经确认后放入回收站。
“全部照片”可按来源线索（截图、微信、QQ、下载）、拍摄相机、文件类型、焦距和光圈筛选。来源线索从文件名和文件夹名推断，未带明显标记的手机截图可能无法识别；拍摄参数以原文件 EXIF 为准，首次建立索引会在后台运行。
主界面和大图主要图标改用随安装包提供的 Google Material Symbols，品牌图标和浏览器应用窗口改为深色暖金风格；字体离线可用。Material Symbols 按 Apache License 2.0 使用，许可文件位于 THIRD-PARTY-NOTICES。

1.0.0beta9 筛选与大图浏览
全部照片筛选支持每个类别只看、排除及自定义多选，可组合使用。多选照片时按 Esc 退出选择。
大图新增“适应屏幕 / 100% 原图”切换（快捷键 F）；手动选择的大小模式在切换照片时保持。全屏时点击照片左右半屏即可翻页，鼠标指针显示方向；上下菜单只在指针靠近顶部或底部时同时展开，点击照片不会唤出菜单。图库窗口标题栏与界面统一为深色。

1.0.0beta10 独立桌面应用
图库改为内嵌 Microsoft Edge WebView2 的独立 Windows 窗口，任务栏、标题栏、应用图标和窗口控制均由应用自身管理；启动时不会打开外部 Edge 或 Chrome 窗口。重复启动会唤醒已有窗口，不会产生多个图库实例。
全屏大图改为控制整个原生窗口，进入后真正占满屏幕，Esc 可恢复。升级继续沿用原照片索引、相册、收藏、语言设置和浏览来源。

存储设备：照片来源支持 SD 卡、USB 外接存储和本机磁盘；显示名称、连接状态与可用空间，支持插拔自动刷新。
